# Data Warehousing Project

This is a college learning project created to understand and gain hands-on experience with the fundamentals of **Data Warehousing**.

The project focuses on learning how raw data can be collected, cleaned, transformed, organized, and stored in a data warehouse so that it can be efficiently used for analysis and reporting.

## Project Objectives

The main goal of this project is to strengthen my practical understanding of Data Warehousing concepts by implementing them step by step.

Through this project, I am learning:

- Fundamentals of Data Warehousing
- ETL/ELT processes
- Data cleaning and transformation
- Data integration
- Dimensional modeling
- Fact and dimension tables
- Star Schema
- SQL for analytical queries
- Data aggregation and analysis
- Working with structured and historical data

## Project Workflow

